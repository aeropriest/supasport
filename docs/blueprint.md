# **App Name**: SupaSport Hub

## Core Features:

- Secure User Authentication: Implements distinct login flows for Coaches (email/password, Google SSO) and the Admin (specific phone number/fixed password).
- Coach Dashboard & Calendar: Provides coaches with a personalized interface featuring a dynamic calendar (daily/list views) to manage their lessons.
- Lesson Scheduling & Booking: Coaches can schedule 1-hour lessons, specifying date, start time, and attaching a client.
- Integrated Client Management: Allows coaches to add new clients to a central database or select from existing ones for lesson assignments. Admin can view the full client database.
- Lesson Completion Marking: Coaches can update the status of lessons to 'completed' within their calendar view.
- Admin Reporting & Coach Overview: Enables the Admin to view a comprehensive list of all coaches, review their schedules, and track all completed lessons across the academy.
- AI-powered Lesson Feedback Tool: An AI tool to assist coaches in quickly generating tailored feedback summaries or preliminary lesson plan suggestions for clients based on performance input.

## Style Guidelines:

- Primary color: Energetic Blue (#2296EE). This hue, a professional and dynamic blue, embodies trust and activity, aligning with the sports academy's purpose. It stands out clearly against lighter backgrounds for important interactive elements and branding.
- Background color: Soft Sky (#EBF4FA). A very light, desaturated blue derived from the primary hue provides a clean, calming backdrop, reducing eye strain for prolonged use in scheduling and client management. This ensures focus remains on content without competing for attention.
- Accent color: Refreshing Teal (#6ED6C6). Positioned analogously on the color wheel to the primary blue, this hue is brighter and slightly more saturated, designed to draw attention to call-to-action buttons, key status indicators, and subtle highlight elements.
- Body and headline font: 'Inter' (sans-serif) for its modern, highly legible, and objective aesthetic, suitable for clear presentation of schedules, client lists, and performance data.
- Use modern, crisp vector icons that visually represent coaching activities, calendar functions, and client management. Ensure a consistent outline or filled style throughout the application for a cohesive look.
- Implement a fully responsive and adaptive layout optimized for seamless use on mobile phones, tablets, and desktop screens. Prioritize clear hierarchical organization for calendar views, client lists, and the administrative dashboard, ensuring easy navigation and information access across all devices.
- Incorporate subtle, smooth transitions and micro-interactions for calendar view changes, lesson status updates, and form submissions. Animations should enhance the user experience by providing clear visual feedback without being distracting or slowing down interactions.
